# Backend

FastAPI REST API (Python) with PostgreSQL.

Modules:

- `auth` — registration, login, JWT, driver and owner roles
- `parkings` — lots, spaces, rates
- `bookings` — time-slot reservations without double booking
- `payments` — Stripe Checkout and webhook
- `agent` — AI assistant (LLM with function calling)
- `forecast` — occupancy prediction using the trained ML model

Setup instructions will be added in Milestone 2.
